# 🍔 SMASHED! - Interactive Burger Landing Page
A modern, interactive landing page for a smash burger joint, focusing on cinematic animations and premium user experience!

# 💡THE IDEA
This project idea was inspired by a newly opened burger restaurant in my area. I wanted to capture the energy and **juicy** feeling of their food. 
I was thinking how could I create a website for such restaurant and thought of an animation and I desperately wanted to test it out.

# 🌟FEATURES
* **Cinematic Intro Animation:** an automatic frame-by-frame animation (128 frames) showing the burger ingredients stacking up.
* **Idle "Swing" Animation:** a smooth, continuous pedulum effect that starts after the intro, making the burger feel a little bit more alive.
* **Fully Responsive Design:** adapts to mobile phones & tablets, changing the layout from horizontal to vertical.
* **Hamburger Menu:** on mobile devices, the navigation menu appears with a smooth slide-down effect.
* **Background blur:** when the mobile menu is opened, the background content blurs to keep the focus on the navigation

# ⚙️TECH STACK
* **HTML** & **CSS**
* **JavaScript *(vanilla)***
* **GSAP (GreenSock):** for full control over timelines & animations.
* **HTML Canvas API:** for high-performance rendering of the image sequence
